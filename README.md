# אלבום תמונות A4

כלי להכנת אלבום תמונות להדפסה בגודל A4, שעובד בדפדפן (גם באייפון).
התמונות נשמרות רק בדפדפן של המכשיר, ולא נשלחות לשום שרת.

- פיתוח מקומי: `npm install` ואז `npm run dev`
- בנייה: `npm run build` (התוצר בתיקייה `dist`)
- כל דחיפה ל-`main` מעלה את האתר אוטומטית ל-GitHub Pages.

במקור נבנה ב-ChatGPT (גרסה 40). הייצוא המקורי נמצא ב-`original-export/` (לא נכלל ב-git).
